# GPlatesUtils

This is a repository of python scripts to make doing GPlates simulations easier.

## Setup

Place the source in your gplates project folder and use the requirements.txt file.

## The scripts

All of them can have help with the `-h` or `--help` flag.
`init_rotfile.py` makes a .rot file to initialze.
`drift_correction.py` allows drift correction ala Artifexian.
`link.py` relinks the anchored IDs of plates at a certain time (for rifting and collisions).
